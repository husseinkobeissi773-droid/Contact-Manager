# Contact Manager – Version 1

## 📱 About the Project

Contact Manager is a simple Phone Book web application developed as my first university project.

The application allows users to manage their contacts through a simple and user-friendly interface.

This project represents one of my first practical experiences in programming and software development.

## ✨ Features

The application allows users to:

- ➕ Add new contacts
- 📋 View the contact list
- ✏️ Edit existing contacts
- 🗑️ Delete contacts
- 🔎 Manage contacts through a simple interface

## 🛠️ Technologies Used

This project was developed using:

- **HTML** – For creating the structure of the application
- **CSS** – For designing and styling the interface
- **JavaScript** – For implementing the application logic and interactions
